# WexVisuals

Visual mod for Minecraft 1.21.4 Fabric

## Features
- **Trails** - Customizable colored trails behind player
- **3D Hats** - China Hat, Cowboy Hat, Top Hat, Wizard Hat
- **Jump Particles** - Colorful circles when jumping (with rainbow mode)
- **Bunny Model** - Custom player model with ears and tail (WexVisuals style)
- **Small Player** - Scales down your player model to 0.5x
- **HitColor** - Customizable hitbox colors with transparency

## Controls
- **Right Shift** - Open GUI

## Building
1. Install JDK 21
2. Open in IntelliJ IDEA
3. Run `./gradlew build`
4. Find `.jar` in `build/libs/`

## Installation
Copy the built `.jar` to your `mods` folder along with Fabric API.

## GUI
Dark red themed GUI with rounded buttons and color pickers.
